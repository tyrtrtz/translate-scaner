中韩译文工作台 v1.1.11

- 纯文本补匹配增加四组标点等价规则：… 与 ...、，与 ,、; 与 ；、：与 :。去标签后只有这些差异的句子视为同文，唯一非空译文可推荐；状态仍为“唯一译文”，依据注明忽略指定标点差异，原文与译文保留原值。
- 新增最后一轮模糊匹配，最低相似度 80%。普通检索在整句匹配后执行；合并/拆分入口在结构推荐后执行。
- 仅补查仍为“基准文件中找不到”的源句与此前无候选的基准位置，不覆盖已有整句、合并、拆分推荐，不替代此前的缺译或冲突判断。
- 最高分的非空译文无并列冲突时写入推荐，状态为“模糊推荐·待复核”，依据注明相似度。所有达到阈值的候选保留；同分不同译文待确认，同分同译取首条来源。
- 匹配明细末尾新增“基准中文”“相似度”，可筛选“匹配方式=模糊匹配”，并对相似度进行数值筛选。成功推荐同步计入统计，同文同译的源句不再列入未推荐明细。
- 比较时沿用标签及换行清理，译文保留原值并对齐首尾换行。文字相似度不能保证语义相同，数字、否定词或短句变化仍须人工复核。

本次同时修正完成提示，完整列出合并、拆分与模糊推荐的待复核状态。
