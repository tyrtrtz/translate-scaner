中韩译文工作台 v1.1.7

- 拆分规则补充数字后的中英文分号、逗号，继续支持顿号、点号等格式。中韩可使用不同分隔符；小数和千位分隔符不作为选项编号。
- 中文无编号时支持按实际或字面换行拆分，保留每段韩语原值和编号。支持部分段匹配，中间未命中的段不会导致后续译文错位；位置重复、来源冲突及格式不一致均保留原因。
- 试拆分结果新增“分段未匹配”“分段候选”工作表，拆分明细新增“拆分规则”“整组匹配情况”。全部输出供复核，不回填基准 TextTrans，不改动源文件或基准原件。
- 对前两轮没有命中任何基准的源句，去除句尾成对括号及内容后再次匹配。保留句中括号，异常括号不猜测；已有推荐保留，新来源进入明细和覆盖统计，采用的依据注明需要复核。
- 在线更新增加连接与读取中断重试；主发布通道连接失败后，自动尝试本仓库的备用下载地址。继续验证文件大小、SHA256 和 Windows 程序格式，失败不替换原程序。

旧版不知道备用地址：遇到 GitHub 发布附件下载失败时，需先手动更换本版 exe 一次。之后更新会自动尝试两个通道；客户网络若同时阻断两个通道，仍需更换网络或手动传送 exe。本地设置、忽略记录及已有文件保留。
