# 功能状态与待办

## 已实现

- 表头检查、具体异常原因、勾选批量忽略与恢复、本地设置保存。
- 子目录、隐藏工作表、隐藏行、废弃行四项扫描开关。
- 多基准匹配、全文及纯文本补匹配、首尾换行对齐、推荐与各类明细统计。
- 最后一轮模糊补查，最低相似度 80%，仅处理仍未命中的源句与无候选的基准位置；最高分无译文并列冲突时写入“模糊推荐·待复核”，依据及明细保留百分比和双方中文。
- 未推荐明细排除已获推荐的同文同译重复来源，跨文件及 Sheet 生效；实际推荐、完整明细和统计不变。
- 有效上下文补查、气息去括号、完美匹配标记及上下文查询统计。
- 结构扫描、仅限 char.xlsx 的合并反查、数字编号及无编号换行试拆分，支持部分段定位，韩语编号保留。
- 合并译文用空格连接，补充句中省略号、叹号和句号后的空格；支持唯一长短候选之间省略首尾完整源行的合并。
- 合并与拆分写入基准副本推荐列，分别标记待复核，不覆盖整句推荐与 TextTrans；同步推荐统计、来源使用及部分拆分未推荐原因。
- 数字编号补充分号、逗号；未命中源句增加句尾括号补匹配，保留已有推荐。
- 在线更新增加连接重试和本仓库备用下载通道，仍校验大小、SHA256及程序格式。
- 人工合并复核的导入、保存、撤回及内容变化后失效。
- 两入口共用源行排除规则，整句命中覆盖双方行，避免误列未解释。
- 比较时忽略 color 等英文尖括号标签，原文与候选译文保留标签供复核。
- 复核保存失败撤回本次报告，字段说明与输出同步。
