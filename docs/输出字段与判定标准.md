# 译文检索输出字段与判定标准

版本日期 2026年10月4日

## 使用范围与共同规则

本说明供操作人员与结果复核人员使用，解释译文检索程序每个输出字段的来源、计数单位和推荐依据。结果由基准副本、基准文件统计、源文件统计和匹配明细组成；第一步另外支持导出异常 CSV。推荐依据是确定的中文上下文规则，需要人工确认译文是否适合实际语境。

处理流程为先检查源文件表头，排除忽略项与异常项，再共享一份源文件磁盘索引，逐个处理基准文件并汇总。一个源行可以命中多个基准行；推荐以每个基准行的位置和上下文单独计算，同一中文可能在不同位置获得不同推荐。

中文匹配只去除首尾空白后全文精确比较。内部空格、标点、换行及 Unicode 表示保持不变。空值、全空白与非文本中文不计入有效中文行。这里的“中文”是指定中文列中的有效文本，不按汉字比例判断语言。韩语列非空的数字等值会转成文本，不另行验证语言。

源行取自通过检查的 Sheet 中表头之后的行。已忽略、异常、关闭开关排除的隐藏 Sheet 与隐藏行均不参与匹配和上下文。中文或韩语正文含公式时整张源 Sheet 回滚并跳过，已读的半张表不计入结果。用户修复此前异常的 Sheet 后必须重新检查。

基准文件递归读取所有 xlsx 与 xlsm 文件及全部 Sheet，不受源文件三个扫描开关控制。每张基准 Sheet 的 G1 必须是 Text，从 G2 开始取非空文本；基准 G 列公式会中止本次检索。基准文件名相同但完整路径不同，分别统计。源文件与基准原件均不保存。

行号均为 Excel 原始实际行号，从 1 开始，包含表头行，不是过滤后的记录序号。计数值 0 表示范围内确实没有该类记录；比率分母为 0 时留空。缺少原文、译文、上下文或推荐时相应文字字段留空，不填造内容。

## 上下文推荐的判定顺序

每条记录在同一文件、同一 Sheet 内，取前后各最多三条有效中文记录。前1句是最近的前一条，前2句、前3句依次向前；后1句、后2句、后3句依次向后。空白与非文本中文不占位置；源文件被排除的隐藏行不占位置；中文有效但韩语为空的邻句仍参与。每个单元格整体算一条，不按句号或换行拆句，不跨 Sheet 或文件补齐。

双方上下文中文先去首尾空白，然后只比较同一相对位置，例如前1句对前1句。前句一致数与后句一致数分别为一致位置的数量，均为 0 至 3；缺失位置不算一致。某一侧双方都具有完整三句且三句全部一致，才算一个完整一致侧。

只在中文全文命中的来源中选推荐。空韩语来源保留在计数和明细中，但不进入推荐候选。不同非空韩语的判断只去首尾空白，保留内部空白、标点、换行和 Unicode 表示。推荐单元格写入选中来源的韩语原值。

| 情况 | 处理标准 |
| --- | --- |
| 未匹配 | 没有中文全文命中的源行。推荐韩语与来源为空；依据说明未命中。 |
| 全部缺译 | 至少命中一条中文，但所有韩语为空或全空白。推荐韩语与来源为空。 |
| 唯一译文 | 所有命中来源仅有一种不同的非空韩语。即使有重复来源或缺译来源，也可直接推荐该译文。 |
| 上下文推荐 | 存在不同韩语时，按完整一致侧数优先、再按一致位置总数优先排序。最高分至少有一侧完整一致，且最高分只对应一种韩语，才推荐。 |
| 待确认 | 存在不同韩语，但没有完整一侧三句一致，或不同韩语在最高分并列。部分相同只作为证据，不自动选译文。 |
| 相同译文的来源选择 | 唯一译文或同分最高候选韩语相同时，取上下文得分最高的来源；同分取读取顺序首条。源文件按路径排序，Sheet 按工作簿顺序，行按实际行号。 |

## 推荐得分与复核示例

得分是两个整数的优先级组合，不是翻译质量分数，也不是置信度百分比。先比较完整一致侧数，再比较一致位置总数。前后都完整一致得到 2 个完整一致侧、6 个一致位置；一侧完整一致加另一侧两处一致得到 1 个完整一致侧、5 个一致位置。

相同中文在甲基准文件的前后三句符合来源甲，在乙基准文件的前后三句符合来源乙，会分别推荐对应译文。不会把某次推荐作为这个中文在所有文件中的固定答案。

原始冲突标记不会因为已获得推荐而消失。源文件冲突描述的是所有参与来源是否提供不同韩语；上下文推荐描述的是当前基准位置更适合哪一个来源。保留两者便于人工复核。

| 对比情况 | 结果与原因 |
| --- | --- |
| 来源甲前3后3一致 来源乙前3后1一致 | 甲为 2 侧、6 处；乙为 1 侧、4 处。推荐甲。 |
| 来源甲前3后2一致 来源乙前3后1一致 | 都为 1 侧，甲有 5 处、乙有 4 处一致。推荐甲。 |
| 来源甲前3后0一致 来源乙前0后3一致 | 都为 1 侧、3 处。韩语不同时待确认；相同时可选稳定首条来源。 |
| 双方边界只有两句 且两句相同 | 没有完整三句的一侧。若存在不同韩语，待确认，不把缺失第三句当作相同。 |
| 最高分来源的韩语为空 | 该来源不能推荐；继续在非空韩语来源中按同样规则比较。 |
| 四条以上匹配 | 原始三组候选字段留空，但仍比较全部候选，并写推荐列；完整证据在匹配明细中。 |

## 基准副本的每一列

输出位于基准匹配结果目录，沿用原基准的相对目录、文件名、Sheet 和行号。原始 A 至 Q 列保持原值、公式及格式；G 列 Text 是检索输入。R 至 AG 属于程序结果区，原件这些列任一单元格已有内容或公式时，检索中止，避免覆盖。

以下结果仅写入 G 列为有效文本的基准行；空白、非文本行的结果区不写内容。第 1 行新增表头。原始三组候选按源行读取顺序列出，不按推荐排序；重复中文或相同韩语的来源不合并。

| 字段 | 来源与判定标准 |
| --- | --- |
| R U X  匹配中文1 匹配中文2 匹配中文3 | 第 1、2、3 条命中来源的中文原值，保留原首尾空白。仅匹配条数 1 至 3 时展开，超过 3 条或对应序号不存在时为空。 |
| S V Y  匹配韩语1 匹配韩语2 匹配韩语3 | 同一候选源行的韩语原值；原值为空时为空，全空白原值保留；展开条件与对应中文相同。 |
| T W Z  来源路径 / Sheet / 行号1 来源路径 / Sheet / 行号2 来源路径 / Sheet / 行号3 | 对应候选的完整源文件路径、Sheet 名称和实际行号。展开条件与对应中文相同。 |
| AA  匹配条数 | 该基准中文对应的全部参与源行数。同中文出现在不同位置分别计数，空韩语也计数。未命中为 0。 |
| AB  缺译条数 | 上述全部命中源行中，韩语为空或去首尾空白后为空的行数。未命中为 0。 |
| AC  译文冲突 | 至少两种不同的非空韩语为“是”；命中但不足两种为“否”；无中文命中为“未匹配”。空韩语不算一种译文。 |
| AD  推荐韩语 | 选中推荐来源的韩语原值，保留首尾空白。仅唯一译文或上下文推荐填写，其他状态为空。 |
| AE  推荐来源 | 所选来源的完整路径、Sheet 名称及实际行号。仅有推荐时填写，可与三组候选中的任一条或未展开的候选对应。 |
| AF  推荐依据 | 记录本行推荐或无法推荐的具体原因。上下文推荐写前句、后句一致数及得分；唯一译文说明仅一种非空韩语和来源选择规则。 |
| AG  推荐状态 | 取未匹配、全部缺译、唯一译文、上下文推荐、待确认之一，按前述顺序判定。 |

## 基准文件匹配统计的每个字段

基准文件匹配统计.xlsx 包含文件统计、Sheet统计、总体统计。文件统计一文件一行，Sheet统计一 Sheet 一行；无中文、零命中也列出。总体统计各计数是逐文件相加，三个比率使用合计分子除以合计分母，不能平均文件百分比。

统计单位均是基准行。例如一个源行命中 100 个基准行，中文匹配行数计 100；源文件匹配统计仍只计这个源行一次。重复中文在不同基准文件不去重。

| 字段 | 来源与判定标准 |
| --- | --- |
| 文件名 完整路径 Sheet | 文件名为输入基准文件名；完整路径为本次输入的绝对路径。Sheet 仅在 Sheet统计中列出，名称取原工作簿。 |
| 非空中文行数 | 当前文件或 Sheet 的 G2 起有效文本中文行数。重复中文逐行计数。 |
| 中文匹配行数 | 上述行中至少命中一个源行的基准行数，不是源候选条数。 |
| 有译文行数 | 至少有一个中文命中来源的韩语非空的基准行数；存在冲突或待确认也计入。 |
| 推荐行数 | 推荐状态为唯一译文或上下文推荐的基准行数。 |
| 未匹配行数 | 非空中文行数减中文匹配行数。 |
| 命中但全缺译行数 | 中文已命中，但所有来源韩语为空或全空白的基准行数。等于中文匹配行数减有译文行数。 |
| 冲突行数 | 对应至少两种不同非空韩语的基准行数。重复中文出现多行逐行计数。 |
| 冲突已推荐行数 | 上述冲突行中，已通过上下文取得推荐的行数。 |
| 冲突待确认行数 | 冲突行数减冲突已推荐行数。 |
| 中文匹配率 | 中文匹配行数除以非空中文行数，以百分比保留两位小数显示。分母为零时留空。 |
| 译文覆盖率 | 有译文行数除以非空中文行数，显示规则同上。 |
| 推荐率 | 推荐行数除以非空中文行数，显示规则同上。 |
| 基准文件数 基准 Sheet 数 | 仅总体统计列出：本次读取的基准文件数量、这些文件的 Sheet 总数，包括有效中文为零的文件和 Sheet。 |

## 源文件匹配统计的每个字段

源文件匹配统计.xlsx 包含文件统计、Sheet统计和跳过清单。文件统计按输入源文件合计；Sheet统计仅列成功读完整张正文的参与 Sheet。所有计数的范围排除忽略、异常与扫描开关排除的内容。

源匹配率以源行计数：一源行命中任意基准即计一次，与命中了多少个基准行无关。它表示现有来源中多少中文被基准使用，不等于基准译文覆盖率。

| 字段 | 来源与判定标准 |
| --- | --- |
| 文件名 完整路径 Sheet | 均取输入源文件与原 Sheet。文件统计不含 Sheet 字段；Sheet统计与跳过清单包含。 |
| 参与 Sheet 数 | 文件统计中，正文完整读取成功的 Sheet 数。即使没有有效中文也属于参与 Sheet。 |
| 跳过 Sheet / 文件项数 | 该文件在跳过清单中的项目数量；可能是具体 Sheet 或整文件错误项，不一定等于工作簿的 Sheet 总数。 |
| 非空中文行数 | 参与范围内，表头之后有效文本中文行数。 |
| 匹配行数 | 上述源行中，中文命中至少一个基准 G 列文本的行数。 |
| 未匹配行数 | 非空中文行数减匹配行数。 |
| 匹配率 | 匹配行数除以非空中文行数，显示两位小数百分比。分母为零或全部跳过时留空。 |
| 处理状态 | 文件统计取已扫描、部分跳过、全部跳过。成功 Sheet 与跳过项目同时存在为部分跳过；仅跳过项目为全部跳过。 |
| 缺译行数 | 当前源范围内，中文有效且韩语为空或全空白的源行数，包括没有命中基准的源行。 |
| 冲突中文数 | 当前源范围内出现过的冲突中文种类数。同中文在该范围重复只计一次；是否冲突按全部参与源文件共同判断，包括未命中基准的中文。 |
| 跳过原因 | 跳过清单中填写具体异常、正文读取失败、本地已忽略、开关排除隐藏 Sheet 等原因。整文件问题的 Sheet 可为空。 |

## 匹配明细的每个字段

匹配明细.xlsx 的匹配明细 Sheet 每行对应一个源行与一个基准行。某源行匹配多个基准行会逐项展开；候选超过三条也全部列出。列 A 至 L 是原匹配记录，M 至 W 是上下文及推荐证据。

| 字段 | 来源与判定标准 |
| --- | --- |
| A 基准文件名 B 基准完整路径 | 当前匹配对应的输入基准文件名及绝对路径，不是输出副本路径。 |
| C 基准 Sheet D 基准行号 | 基准原 Sheet 名与 G 列中文所在实际行号。 |
| E 源文件名 F 源完整路径 | 本项匹配来源的输入源文件名及绝对路径。 |
| G 源 Sheet H 源行号 | 中文与韩语所在原 Sheet 名和实际行号。 |
| I 源中文 J 韩语 | 该源行的原始中文和韩语值，保留首尾空白；韩语非文本的值已转为文本。 |
| K 缺译 | 本源行韩语为空或全空白为是，否则为否。 |
| L 译文冲突 | 本源中文在全部参与来源中有至少两种不同非空韩语为是，否则为否。 |
| M 基准前3句 N 基准后3句 | 当前基准位置前后最多三条有效中文。每条显示相对位置、实际行号和去首尾空白后的中文；没有邻句则为空。 |
| O 来源前3句 P 来源后3句 | 当前源位置的对应上下文，格式同上。原始行号可不连续，且只来自该源 Sheet。 |
| Q 前句一致数 R 后句一致数 | 双方相同相对位置中文一致的数量，各取 0 至 3。没有邻句为 0，不补齐缺失位置。 |
| S 完整一致侧数 | 前侧完整三句都一致计 1，后侧完整三句都一致再计 1，范围 0 至 2。 |
| T 一致位置总数 | 前句一致数加后句一致数，范围 0 至 6。 |
| U 推荐来源 | 本候选正是该基准行最终选中的来源为是，否则为否。相同韩语的其他来源仍为否；无推荐时所有候选均为否。 |
| V 推荐状态 W 推荐依据 | 取该基准行的判定，与基准副本 AG、AF 一致。同一基准行展开的不同候选均重复这一最终判定；Q 至 T 则分别描述当前候选。 |

## 未匹配缺译与冲突明细的每个字段

匹配明细.xlsx 的未匹配明细、缺译明细、译文冲突三个 Sheet 均以源行为单位，每个符合条件的源行一项，不按基准文件展开。同一源行可出现在多个分类 Sheet 中。

未匹配明细列出未命中任意基准中文的源行；缺译明细列出所有空韩语源行，包含命中与未命中；译文冲突列出冲突中文的全部来源，包含其中的缺译行和未命中基准的中文。

| 字段 | 来源与判定标准 |
| --- | --- |
| A 源文件名 B 源完整路径 | 输入源文件名及绝对路径。 |
| C 源 Sheet D 源行号 | 原工作表名称与实际行号。 |
| E 源中文 F 韩语 | 对应源行原值；中文保留首尾空白，非文本韩语转为文本，空韩语为空。 |
| G 命中基准 | 本源行中文命中至少一个基准有效中文为是，否则为否。未匹配明细全部为否。 |
| H 缺译 | 本源行韩语为空或全空白为是，否则为否。缺译明细全部为是。 |
| I 非空韩语种类数 | 该中文在全部参与源行中不同的非空韩语数量，只去韩语首尾空白后比较。可以为 0、1 或更多；冲突明细至少为 2，空韩语不增加种类数。 |

## 表头异常 CSV 的每个字段

第一步导出的异常 CSV 每项一行，只包含未忽略的检查异常，UTF-8 带 BOM 便于 Windows Excel 显示中文和韩语。无异常时只有列名。表头检查默认前 10 个实际行号，可输入任何大于等于 1 的整数。

表头采用完整名称匹配，先进行 Unicode NFKC 规范化并去首尾空白。中文、韩语表头必须在同一行且各只有一个候选列；缺失、不同行、多个候选等原因分别报告。此规则与正文只去首尾空白不同。通过检查仅说明表头明确，不代表正文或译文质量合格。

| 字段 | 来源与判定标准 |
| --- | --- |
| 文件名 | 发生异常的原文件名。 |
| 相对路径 | 该文件相对所选源文件夹的路径。 |
| 完整路径 | 异常输入文件的绝对路径。 |
| 工作表 | 异常 Sheet 名；整文件无法读取或格式不支持时为空。 |
| 显示状态 | 原 Sheet 的 visible、hidden、veryHidden 等状态；文件级问题可能为空。 |
| 异常原因 | 说明缺少哪种表头、另一种找到的位置、重复候选或文件读取问题，不笼统判断整张表没有译文。 |
| 中文表头位置 韩语表头位置 | 检查范围内名称命中的单元格坐标与原文字，例如 A3=台词、B3=한국어。没有候选为空；这是候选位置，不必然是最终合法表头。 |
| 检查前几行 | 本次输入的表头搜索范围上限，即实际行号 1 至该值。排除隐藏行也不会向后补足。 |
| 检查依据 | 具体检查范围、隐藏行排除说明，以及顶部最多三个非空行和最多三个候选行的文本样例。每行最多 32 项，每项最多 80 字，超长会截断标记。 |
| 该文件已通过的工作表 | 同文件已通过检查的 Sheet 名，以分号连接；没有为无。帮助识别仅部分 Sheet 异常的文件。 |

## 汇总校验与结果使用

基准统计满足：非空中文行数等于中文匹配行数加未匹配行数；中文匹配行数等于有译文行数加命中但全缺译行数；冲突行数等于冲突已推荐行数加冲突待确认行数。推荐行数不大于有译文行数，有译文行数不大于中文匹配行数。

例：一个基准文件有 10 个有效中文行，其中 8 行中文命中、6 行存在非空韩语、5 行已有推荐，则未匹配为 2、命中但全缺译为 2；中文匹配率为 80.00%，译文覆盖率为 60.00%，推荐率为 50.00%。待确认仍可能属于有译文，不能因此称为缺译。

源文件冲突中文数跨文件不宜直接相加：同一冲突中文在两个文件中出现，每个文件各计一次，整体仅一种冲突中文。窗口中的冲突中文数取整体不同中文数量；缺译行数取整体空韩语源行数；完整匹配对应条数取匹配明细的对应项数。基准文件、基准行、匹配行、推荐行分别取基准总体统计。

每次成功检索创建独立的新结果目录，失败时清理该次临时目录与 SQLite 数据库。第一步检查不会创建匹配目录。副本中的推荐列可作为回填候选；待确认应结合匹配明细逐项复核，源统计和基准统计用于不同方向的覆盖检查。

Excel 明细无记录时只有表头，超过单 Sheet 的 1,048,576 行时自动拆分为带序号的后续 Sheet，每页重新写表头，数据计数不包含这些表头。输出统计及明细的文本均写作文字，原值以等号开头也不会当公式执行；异常 CSV 相应文字字段若以等号、加号、减号或 @ 开头则加单引号保护。

文件读取按只读和流式方式执行，源正文读取一次，索引及比较依据存于临时 SQLite；不将全部正文汇总到内存。Excel 共享字符串和样式仍可能占用内存。基准副本工作表 XML 流式追加结果，其他 ZIP 部件原样复制，以保留已有样式、公式、图片和宏。
