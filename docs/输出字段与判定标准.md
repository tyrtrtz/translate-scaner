# 译文检索输出字段与判定标准

版本日期 2026年10月21日

## 使用范围与共同规则

本说明供操作人员与结果复核人员使用，解释译文检索程序每个输出字段的来源、计数单位和推荐依据。结果由基准副本、基准文件统计、源文件统计和匹配明细组成；第一步另外支持导出异常 CSV。推荐依据是确定的中文上下文规则，需要人工确认译文是否适合实际语境。

普通检索执行整句各轮匹配。“合并/拆分并生成推荐”另执行结构扫描，在本次结构目录的“推荐结果”中生成包含整句、合并和拆分推荐的综合结果；两个入口都保留原件及 TextTrans。结构推荐仅补充没有整句推荐的位置，分别标记“合并推荐·待复核”“拆分推荐·待复核”。预览不等于实际写入，实际写入与未写入原因分别见匹配明细的“合并拆分推荐”“结构推荐未写入”。

处理流程为先检查源文件表头，排除忽略项与异常项，再共享一份源文件磁盘索引，逐个处理基准文件并汇总。一个源行可以命中多个基准行；推荐以每个基准行的位置和上下文单独计算，同一中文可能在不同位置获得不同推荐。

第一轮中文匹配只去除首尾空白后全文精确比较；对第一轮尚未推荐的基准行，再执行下述纯文本补匹配，已有推荐不覆盖。内部空格、标点、换行及 Unicode 表示保持不变。空值、全空白与非文本中文不计入有效中文行。这里的“中文”是指定中文列中的有效文本，不按汉字比例判断语言。韩语列非空的数字等值会转成文本，不另行验证语言。

源行取自通过检查的 Sheet 中表头之后的行。“包含废弃行”默认关闭，特殊说明列中去首尾空白并规范化 Unicode 后恰为废弃的行跳过，不参与正文、上下文、统计和明细；勾选后参与，没有该列时照常处理。该列在中韩表头同一行按名称识别，多个同名列会提示确认。已忽略、异常、关闭开关排除的隐藏 Sheet 与隐藏行均不参与匹配和上下文。中文或韩语正文含公式时整张源 Sheet 回滚并跳过，已读的半张表不计入结果。用户修复此前异常的 Sheet 后必须重新检查。

基准文件递归读取所有 xlsx 与 xlsm 文件及全部 Sheet，不受源文件四个扫描开关控制。每张基准 Sheet 在前 N 个实际行号中按完整名称查找唯一的 Text 表头（忽略首尾空白并规范化 Unicode，保留大小写）；N 沿用第一页“检查行数”，默认 10，最低 1。Text 可以位于任意列或上述范围内的任意行，从表头下一行开始取该列非空文本；该列公式会中止本次检索。找不到或找到多个 Text 时提示查找范围或候选坐标。TextTrans 无论位于哪列均原样保留，不自动覆盖；缺少 TextTrans 也可检索。基准文件名相同但完整路径不同，分别统计。源文件与基准原件均不保存。

行号均为 Excel 原始实际行号，从 1 开始，包含表头行，不是过滤后的记录序号。计数值 0 表示范围内确实没有该类记录；比率分母为 0 时留空。缺少原文、译文、上下文或推荐时相应文字字段留空，不填造内容。

源表同时具有特殊说明、说话角色名两列表头且两列值均为空时，该行作为无效说明从匹配、上下文和统计分母排除；缺少任一表头不套用这项规则。正式匹配与结构扫描共用此判断。特殊说明或需要判断的角色名单元格为公式、同名元数据列重复时跳过该 Sheet 并保留原因。

特殊说明为气息的源行额外支持忽略双方中文中成对的中文或英文括号及其中说明后匹配，支持嵌套；仅括号说明清理后为空时不新增候选，括号异常时保留原文比较。前两轮普通台词的括号保持有效，未命中的源句可进入下述句尾补匹配。中文与韩语原值均保留，韩语种类仍按原韩语去首尾空白后区分。

## 纯文本补匹配规则

先完成全部基准行的精确匹配和推荐；仅对仍未推荐的基准行执行补匹配，不覆盖第一轮已经取得的推荐。即使某个源行已在其他基准位置被使用，仍可作为未完成基准行的候选。

对两边中文移除成对花括号占位符（如 `{playername}`）、以英文字母开头的尖括号标签（如 `<color=#3266b4>`、`</color>`）、实际 CR/LF 与字面量 `\n` / `\r`，再去首尾空白并全文比较。其余文字、数字、标点、内部空格与 Unicode 表示保持不变，不做模糊匹配。清理后为空的句子不参与第二轮，也不占其上下文位置。

前后各取最多三条清理后非空的有效中文台词，演出、气息按下述有效上下文规则向外补查，保持同文件、同 Sheet 的实际顺序和行号。双方上下文采用同样的标签清理规则。补匹配仍按唯一非空译文、完整前3句或后3句一致及同分待确认等现有规则决定；韩语种类只去首尾空白比较，不去韩语标签合并不同译文。

补推荐成功时，基准副本 AF 及匹配明细 W 写入“仅纯文本匹配，仍需复核标签”，并附原推荐理由；X 写入纯文本补匹配。AD 与候选单元格保留来源韩语及标签，只按基准原文执行原有首尾换行规则；不会自动修复代码、占位符或颜色标签。

基准副本候选、条数、缺译与冲突，以及两类统计和未推荐明细均根据全部阶段实际候选关系输出。源行在不同基准位置命中时只计一次；补推荐成功的来源不再列入未推荐明细。纯文本阶段不向已有精确推荐的基准新增标签不同来源；句尾去括号阶段可以新增符合条件的源行，但保留已有推荐。未进入任一实际候选的源行仍属未匹配。

源文件冲突统计与译文冲突 Sheet 仍按含标签的原中文全文分组；基准副本 AC 及匹配明细 L 按当前基准实际候选判断。不同标签中文的韩语可能在补匹配中构成基准冲突，而源文件的原中文分组不构成冲突，两者口径不同。

## 句尾去括号补匹配规则

前两轮结束后，对未进入任何实际候选的源行，先按纯文本规则清理标签，再去掉句尾完整成对的中文或英文括号及内容，重新查找所有基准。支持连续、嵌套括号；不删除句中括号，异常括号保持原文，处理后为空不参与。同一源句可同时补匹配多个基准位置。已在其他基准命中过的源行不进入此轮。

源中文、韩语和标签原值保留。新增候选计入明细、匹配条数、缺译、冲突与覆盖统计；已有推荐来源和状态保持不变，推荐依据注明“保留先前匹配阶段推荐”，所以该行也可能同时出现新增冲突标记。此前没有推荐的行，新旧全部候选共同按原规则竞争，避免新增候选掩盖已有冲突。

匹配方式为句尾去括号补匹配；采用这种来源的推荐依据注明“忽略源中文句尾括号说明后匹配，仍需复核”及“仅纯文本匹配，仍需复核标签”。上下文沿用纯文本比较，不批量删除普通邻句的句尾括号，不改变韩语种类判定。

## 上下文推荐的判定顺序

每条记录在同一文件、同一 Sheet 内，取前后各最多三条有效中文记录。前1句是最近的前一条，前2句、前3句依次向前；后1句、后2句、后3句依次向后。空白与非文本中文不占位置；源文件被排除的隐藏行不占位置；中文有效但韩语为空的邻句仍参与。每个单元格整体算一条，不按句号或换行拆句，不跨 Sheet 或文件补齐。

第一轮上下文只去首尾空白，第二、三轮同时去标签和换行并跳过清理后为空的记录，然后只比较同一相对位置，例如前1句对前1句。前句一致数与后句一致数分别为一致位置的数量，均为 0 至 3；缺失位置不算一致。某一侧双方都具有完整三句且三句全部一致，才算一个完整一致侧。

源上下文中演出、气息行不占三句有效台词名额，继续向外检查；中文为空的演出、气息也计入查询数量。若特殊行与基准当前邻句同文，则同时越过双方，气息同文判断忽略括号说明；否则只跳源行。普通台词按顺序逐位置比较，不能跳过不一致台词向外凑数。到达 Sheet 边界不足三句时，不把缺少的句子当成一致。

上下各三句有效台词全部一致时，该候选标为完美匹配。此标记只描述上下文证据，不等同于被推荐：缺译或不同译文同分仍不能推荐。唯一译文或单侧完整一致沿用既有推荐规则，推荐依据区分完美与非完美。

在本轮中文匹配的来源中选推荐：第一轮按原中文全文相等，第二轮按清理标签后的正文全文相等；第三轮按上述句尾处理新增候选，并与该位置已有候选共同评估。空韩语来源保留在计数和明细中，但不进入推荐候选。不同非空韩语的判断只去首尾空白，保留内部空白、标点、换行和 Unicode 表示。推荐单元格写入选中来源韩语，按基准补删首尾换行，不影响匹配与排序。

| 情况 | 处理标准 |
| --- | --- |
| 未匹配 | 本次所有阶段均未取得候选源行。推荐韩语与来源为空；依据说明未命中。 |
| 全部缺译 | 至少命中一条中文，但所有韩语为空或全空白。推荐韩语与来源为空。 |
| 唯一译文 | 所有命中来源仅有一种不同的非空韩语。即使有重复来源或缺译来源，也可直接推荐该译文。 |
| 上下文推荐 | 存在不同韩语时，按完整一致侧数优先、再按一致位置总数优先排序。最高分至少有一侧完整一致，且最高分只对应一种韩语，才推荐。 |
| 待确认 | 存在不同韩语，但没有完整一侧三句一致，或不同韩语在最高分并列。部分相同只作为证据，不自动选译文。 |
| 相同译文的来源选择 | 唯一译文或同分最高候选韩语相同时，取上下文得分最高的来源；同分取读取顺序首条。源文件按路径排序，Sheet 按工作簿顺序，行按实际行号。 |

## 推荐得分与复核示例

得分是两个整数的优先级组合，不是翻译质量分数，也不是置信度百分比。先比较完整一致侧数，再比较一致位置总数。前后都完整一致得到 2 个完整一致侧、6 个一致位置；一侧完整一致加另一侧两处一致得到 1 个完整一致侧、5 个一致位置。

相同中文在甲基准文件的前后三句符合来源甲，在乙基准文件的前后三句符合来源乙，会分别推荐对应译文。不会把某次推荐作为这个中文在所有文件中的固定答案。

原始冲突标记不会因为已获得推荐而消失。源文件冲突描述的是所有参与来源是否提供不同韩语；上下文推荐描述的是当前基准位置更适合哪一个来源。保留两者便于人工复核。

| 对比情况 | 结果与原因 |
| --- | --- |
| 来源甲前3后3一致 来源乙前3后1一致 | 甲为 2 侧、6 处；乙为 1 侧、4 处。推荐甲。 |
| 来源甲前3后2一致 来源乙前3后1一致 | 都为 1 侧，甲有 5 处、乙有 4 处一致。推荐甲。 |
| 来源甲前3后0一致 来源乙前0后3一致 | 都为 1 侧、3 处。韩语不同时待确认；相同时可选稳定首条来源。 |
| 双方边界只有两句 且两句相同 | 没有完整三句的一侧。若存在不同韩语，待确认，不把缺失第三句当作相同。 |
| 最高分来源的韩语为空 | 该来源不能推荐；继续在非空韩语来源中按同样规则比较。 |
| 四条以上匹配 | 原始三组候选字段留空，但仍比较全部候选，并写推荐列；完整证据在匹配明细中。 |

## 基准副本的每一列

基准匹配结果目录中的副本沿用原目录、文件名、Sheet 与行号，原有列（包括 Text、TextTrans）的原值、公式和格式保留；按 Text 表头定位输入列。原表头未超过 Q 列时结果写入 R 至 AG；表头延伸到 R 列或更右时，结果在最后一个非空表头右侧依次追加 16 列。下面的列字母描述默认布局，顺延时以相同表头名称为准。目标结果列已有内容或公式时中止检索，已有结果表头也拒绝重复回填，避免覆盖。

结果仅写入 Text 表头之后的有效文本行，在识别出的表头行新增结果表头。整句候选按源行读取顺序展开，重复来源不合并；实际采用的结构推荐在其后作为一组候选追加，中文取目标基准原文，韩语取合并或拆分处理结果，完整源值见结构复核表。空白与非文本行不写结果。

输出换行按每个基准行的 Text 列原文判定：基准开头无换行，删除输出开头的换行；基准结尾无换行，删除输出结尾的换行。两侧分别处理，适用于 R/U/X 匹配中文、S/V/Y 匹配韩语与 AD 推荐韩语。换行包括 LF、CRLF、CR，以及夹在首尾空白中的换行；补删仅作用于首尾换行，保留空格、制表符和内部换行。基准某侧有换行时，来源该侧已有换行则原样保留，没有则在对应首尾补一个 LF；不统一已有换行的数量。空值与全空白译文不补换行。匹配、推荐排序、计数及冲突判断不变，明细中的源中文和韩语仍保留原值。

| 字段 | 来源与判定标准 |
| --- | --- |
| R U X  匹配中文1 匹配中文2 匹配中文3 | 第 1、2、3 条命中来源的中文，按基准补删首尾换行。仅匹配条数 1 至 3 时展开，超过 3 条或对应序号不存在时为空。 |
| S V Y  匹配韩语1 匹配韩语2 匹配韩语3 | 同一候选韩语，按基准补删首尾换行；空值为空。展开条件与对应中文相同。 |
| T W Z  来源路径 / Sheet / 行号1至3 | 对应候选的完整源文件路径、Sheet 名称和实际行号。展开条件与对应中文相同。 |
| AA  匹配条数 | 整句各轮实际候选源行数，加实际写入的结构推荐组数。同一来源与基准位置在整句阶段只计一次；结构推荐每个基准最多一组，多行合并计一组。未采用的结构候选不增加数量。未命中为 0。 |
| AB  缺译条数 | 上述全部命中源行中，韩语为空或去首尾空白后为空的行数。未命中为 0。 |
| AC  译文冲突 | 至少两种不同的非空韩语为“是”；命中但不足两种为“否”；无中文命中为“未匹配”。空韩语不算一种译文。 |
| AD  推荐韩语 | 唯一译文、上下文推荐采用选中来源韩语；合并或拆分推荐采用对应处理结果，均按基准补删首尾换行。其他状态为空。 |
| AE  推荐来源 | 所选来源的完整路径、Sheet 名称及实际行号。仅有推荐时填写，可与三组候选中的任一条或未展开的候选对应。 |
| AF  推荐依据 | 整句记录推荐或无法推荐原因、上下文得分或补匹配方式。合并记录采用条件、邻句证据、首尾截取和标点空格规则；拆分记录规则、第几段、总段数及原文和韩文字符位置，均提示复核。 |
| AG  推荐状态 | 整句取未匹配、全部缺译、唯一译文、上下文推荐、待确认。实际写入结构推荐时取合并推荐·待复核或拆分推荐·待复核；已有整句推荐不覆盖，竞争的结构候选暂不写入。 |

## 基准文件匹配统计的每个字段

基准文件匹配统计.xlsx 含文件统计、Sheet统计、总体统计。无中文、零命中也列出。总体的基准文件数、基准 Sheet 数包括本次所有基准文件与 Sheet。各计数按文件相加，比率用合计分子除以合计分母。

统计单位均是基准行。例如一个源行命中 100 个基准行，中文匹配行数计 100；源文件匹配统计仍只计这个源行一次。重复中文在不同基准文件不去重。

| 字段 | 来源与判定标准 |
| --- | --- |
| 文件名 完整路径 Sheet | 文件名为输入基准文件名；完整路径为本次输入的绝对路径。Sheet 仅在 Sheet统计中列出，名称取原工作簿。 |
| 非空中文行数 | 当前文件或 Sheet 的 Text 表头之后的有效文本中文行数。重复中文逐行计数。 |
| 中文匹配行数 | 上述行中至少命中一个源行的基准行数，不是源候选条数。 |
| 有译文行数 | 至少有一个中文命中来源的韩语非空的基准行数；存在冲突或待确认也计入。 |
| 推荐行数 | 状态为唯一译文、上下文推荐、合并推荐·待复核或拆分推荐·待复核的基准行数。结构推荐计入此数不代表已通过人工复核。 |
| 未匹配行数 | 非空中文行数减中文匹配行数。 |
| 命中但全缺译行数 | 中文已命中，但所有来源韩语为空或全空白的基准行数。等于中文匹配行数减有译文行数。 |
| 冲突行数 | 对应至少两种不同非空韩语的基准行数。重复中文出现多行逐行计数。 |

| 中文匹配率 | 中文匹配行数除以非空中文行数，以百分比保留两位小数显示。分母为零时留空。 |
| 译文覆盖率 | 有译文行数除以非空中文行数，显示规则同上。 |
| 推荐率 | 推荐行数除以非空中文行数，显示规则同上。 |

## 源文件匹配统计的每个字段

源文件匹配统计.xlsx 包含文件统计、Sheet统计和跳过清单。文件统计按输入源文件合计；Sheet统计仅列成功读完整张正文的参与 Sheet。所有计数的范围排除忽略、异常与扫描开关排除的内容。

## 汇总校验与结果使用

基准统计满足：非空中文行数等于中文匹配行数加未匹配行数；中文匹配行数等于有译文行数加命中但全缺译行数；冲突行数等于冲突已推荐行数加冲突待确认行数。推荐行数不大于有译文行数，有译文行数不大于中文匹配行数。

例：一个基准文件有 10 个有效中文行，其中 8 行中文命中、6 行存在非空韩语、5 行已有推荐，则未匹配为 2、命中但全缺译为 2；中文匹配率为 80.00%，译文覆盖率为 60.00%，推荐率为 50.00%。待确认仍可能属于有译文，不能因此称为缺译。

源文件冲突中文数跨文件不宜直接相加：同一冲突中文在两个文件中出现，每个文件各计一次，整体仅一种冲突中文。窗口中的冲突中文数取整体不同中文数量；缺译行数取整体空韩语源行数；完整匹配对应条数取整句匹配明细项数加实际合并拆分推荐组数；多行合并计一组，每个拆分目标各计一组。基准文件、基准行、匹配行、推荐行分别取基准总体统计。

每次成功检索创建独立的新结果目录，失败时清理该次临时目录与 SQLite 数据库。第一步检查不会创建匹配目录。副本中的推荐列可作为回填候选；待确认应结合匹配明细逐项复核，源统计和基准统计用于不同方向的覆盖检查。

Excel 明细无记录时只有表头，超过单 Sheet 的 1,048,576 行时自动拆分为带序号的后续 Sheet，每页重新写表头，数据计数不包含这些表头。输出统计及明细的文本均写作文字，原值以等号开头也不会当公式执行；异常 CSV 相应文字字段若以等号、加号、减号或 @ 开头则加单引号保护。

文件读取按只读和流式方式执行，源正文读取一次，索引及比较依据存于临时 SQLite；不将全部正文汇总到内存。Excel 共享字符串和样式仍可能占用内存。基准副本工作表 XML 流式追加结果，其他 ZIP 部件原样复制，以保留已有样式、公式、图片和宏。

## 结构扫描与试合并拆分

结构入口保留预览，并在“推荐结果”中生成综合基准副本，写入推荐列、注明待复核；不覆盖原件、TextTrans 或已有整句推荐。源行排除规则与正式匹配共用；整句命中检查采用全文、气息去括号、纯文本比较，并对未命中源句追加句尾去括号补查。已有中文候选但缺译或冲突时不进入合并反查。只有文件名为 char.xlsx 的未命中基准行参与合并，其他文件仍参与整句检查和拆分扫描。

连续结构比较忽略 color、ruby、b、size 等英文尖括号标签及实际和字面换行，保留占位符、内部空格和标点；报告及译文保留标签。窗口不跨 Sheet、空白、非文本、排除行或明确场景变化，默认最多连续8行，可设2至50行，最多拼接16000字符。标签配对检查目前针对 color 和 ruby，其他标签保留供人工复核。

| 报告与字段 | 来源与判定标准 |
| --- | --- |

## 试合并结果与复核字段

候选韩文按源行顺序用一个空格连接，去除每段首尾空白；句中省略号、叹号、句号后补空格，连续标点不拆开，已有空白不重复补，最后句尾不补，小数、英文点分词、标签与占位符内部不改。原始各段另列回查。人工确认具体一组，或单一来源且具有唯一连续邻句证据时生成建议；角色或剧情段冲突、缺译、占位符异常和 color/ruby 标签异常仍会阻止采用。

长短两个基准句可复用连续源行：每个基准均须只有一组来源，短序列严格等于长序列前缀或后缀；此时短句记录省略首侧或尾侧的完整源行数。重复基准位置、其他重叠或多个来源仍不自动采用。单个源单元格内部删减半句而没有明确韩语边界时，不猜测截译。

## 试拆分结果字段

数字编号优先：支持点号、冒号、括号、顿号、中英文分号与逗号，中韩从1连续编号、顺序和段数一致。移除编号和首尾空白（含边缘字面换行）；小数和千位分隔符不识别成编号。字母编号继续只供格式复核。

中文无编号时，按实际或字面换行逐段对应韩语，中韩段数须一致。只去掉两边空白边缘行，内部空行不跳过。每段韩语保留原值和编号，不按中文长度切割。编号歧义、内部空段、中韩占位符差异或 color/ruby 标签跨段等问题保留原因。

优先采用唯一的整组连续对应；否则每个中文分段在全部基准中查找，唯一位置且无其他源分段争用时输出。允许部分匹配，第2段未找到不会让第3段误配第2段韩语。分段数不超过界面的最多连续行数（默认8），正文不超过16000字符。逐段查找不要求全部段都存在，不以源、基准段落顺序推断已确认的语义对应，仅供复核。
