中韩译文工作台 v1.1.5

- 新增默认关闭的“包含废弃行”开关，与现有三个包含选项并列并保存到本地。未勾选时，“特殊说明”标记为“废弃”的源行不参与匹配、上下文、统计和明细。
- 匹配明细.xlsx 新增“未推荐明细”，逐项列出未被任何基准行选为推荐来源的源句。
- 未推荐原因区分“基准文件中找不到”和“基准文件中找到了但不符合推荐规则”，附源文件、Sheet、实际行号、中韩原文、命中基准与缺译标记。
- 跨全部基准文件判断，每个实际源行仅列一次；忽略、异常及开关排除的内容不列入。现有匹配、推荐与统计规则不变。
- 基准文件改为按 Text 表头定位中文列，不再要求 G1；每张 Sheet 可采用不同列和表头行，查找范围沿用“检查行数”（默认 10）。
- TextTrans 位于任意列均保留原值；原表头超过 Q 列时，结果列向右顺延，避免覆盖。表头缺失、重复及结果列已有内容会给出具体提示。
- 启动时后台检查更新，窗口右上角也可手动检查。
- 更新清单随正式发布版本提供，检查更新不依赖 GitHub API 的匿名访问额度。
- 确认更新后自动下载、校验、替换 exe 并重启；扫描和检索期间不安装更新。
- 下载失败不修改原程序，替换或启动失败时尝试恢复旧程序。
- 本地设置、忽略列表、客户源文件和检索结果保留。
- 保留现有匹配规则，按各行基准原文处理匹配中文、韩语及推荐韩语的首尾换行：基准有而结果没有时补一个；基准没有时删除结果对应侧的换行。已有换行和内部换行保留，空译文不补。

之前没有更新功能的 exe 需要手动更换一次。本版之后可直接在程序内更新。
